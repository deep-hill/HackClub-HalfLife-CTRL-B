This is CTRL-B
The modified version of starbie, a desktop pet on a game controller base.

Features-
- Custom Digital Oled Pet
- Pet stuff like napping
- Mood based light, vibration, sound
- Time display
- Ultrasonic based measuring

Parts
- XIAO ESP32-C3
- MPU6050
- DHT11
- Cherry MX Linear Switch (×3)
- MX Keycap R2 (×3)
- 0.96" OLED SSD1306 I2C
- Resistors
- HC-SR04 Ultrasonic Sensor
- Passive Buzzer
- CR2032 Battery Holder PTH
- CR2032 Battery
- LDR GL5528
- RGB LED Common Cathode 5mm
- Vibration Motor (coin type)
- PCF8574T I2C I/O Extension Board
- TM1637 4-Digit 7-Segment Display
- PCB (custom)

It's cool.
